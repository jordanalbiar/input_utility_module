<h1>Input Utility Module</h1>

**One-file powerhouse for fancy text, emojis, and GIFs.**

This new Input Utility Module is a fresh, much simpler version of my original tool. Instead of a complicated setup, it’s now just one single HTML file that you download and open in any browser, with nothing to install and no extra programs needed. It works completely offline for fonts, emojis, and your saved library. The only optional things are a free GIPHY key (for searching GIFs) and an Imgur key (for uploading images) — everything else runs right away with zero hassle.

## ✨ Features

### 🔤 **Font Generator**
- Real-time preview with **12+ stylish fonts** (Fraktur, Bubbles, Full-Width, Double-Struck, Ancient, etc.)
- One-click copy
- Archive favorite phrases to your Library

### 😀 **Emoji Library**
- Full categorized emoji browser
- Multiple styles: System, Twitter (Twemoji), Noto, OpenMoji
- Global favorites with right-click

### 📚 **Library**
- Saved GIFs
- Archived font phrases
- Favorite emojis
- Imgur upload history

### 🌀 **Portal — GIF Search**
- Search **Tenor**, **GIPHY**, **Stickers**, **Imgur**, and **custom sources**
- Trending support
- Infinite scroll
- Reactions quick-search
- Heart to save • Upload to Imgur • Full-screen view

### ⚙️ **Settings**
- Custom color themes & presets
- Adjustable sizes
- GIPHY API key support
- Imgur upload integration
- Add your own GIF API sources
- Full settings export/import

## 🚀 How to Use

1. Download **`Input-Utility-Module.html`**
2. Open the file in your browser (Chrome/Firefox recommended)

**Works completely offline** after first load.
